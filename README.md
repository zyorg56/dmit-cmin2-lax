## CMIN2 是什么线路？为什么 DMIT 洛杉矶值得关注

**CMIN2（China Mobile International Network 2）是中国移动的国际骨干精品网。** 简单说：数据在中国移动的自有专线上跑，不走公共互联网的混合路由，绕路少、拥堵少。对移动宽带和 5G 用户来说，这条线路的体感通常比电信 CN2 GIA 还顺滑——毕竟去程和回程都在自家的网里。

DMIT 洛杉矶 Eyeball 系列（简称 LAX.EB）的线路逻辑是这样的：

- 电信用户：去程走 CN2，回程走 CMIN2
- 联通用户：去程走 CUG 9929，回程走 CMIN2
- 移动用户：去程 CMIN2，回程 CMIN2——双向都在精品线上

IPv6 方面，三网都是 CMIN2，表现比 IPv4 更整齐。

这条线路能吸引人的核心就在这里：**不只是移动友好，联通用户的体验也很稳**，9929 去程配 CMIN2 回程，比很多只优化单向的商家强不少。电信用户也够用，只是如果你是电信重度用户、对延迟极度敏感，可以考虑直接上 LAX.Pro（CN2 GIA 双向）。
